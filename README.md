# Loddboka - The Raffle Book App

Loddboka is a simple and intuitive Android application designed to streamline the process of managing and drawing winners from physical raffle ticket books. It's the perfect digital companion for community events, fundraisers, bazaars, or any occasion that involves a raffle.

## Features

- **Digital Raffle Book Management**: Easily add the raffle books you have for sale. You can specify a color, a series letter, and the start/end numbers for each book.
- **Effortless Winner Drawing**: With the tap of a button, the app randomly draws a winning ticket from the pool of all registered tickets.
- **Drawing History**: Keep track of all the winners that have been drawn.
- **Simple and Clean UI**: The interface is built with Jetpack Compose for a modern and smooth user experience.
- **Multi-Language Support**: The app includes support for multiple languages.
- **Settings Management**: Reset the drawing or clear all raffle book entries to start fresh.

## Technologies Used

- **Kotlin**: The entire app is written in modern Kotlin.
- **Jetpack Compose**: The user interface is built using Google's modern toolkit for building native Android UI.
- **Android Jetpack Components**:
    - **ViewModel**: To store and manage UI-related data in a lifecycle-conscious way.
    - **Navigation Compose**: To handle in-app navigation between screens.
    - **DataStore**: For simple, asynchronous data storage.
- **Material 3**: Following the latest Material Design guidelines for a beautiful and consistent look and feel.

## How to Build

1. Clone the repository.
2. Open the project in Android Studio.
3. Let Gradle sync the dependencies.
4. Build and run the application on an emulator or a physical device.
